# URL Shortener — Capacity Estimation

This document contains initial assumptions for estimating the traffic and storage needs of the URL Shortener.

## Capacity inputs

Define these inputs first:

| Input | Symbol | Example assumption | Notes |
|---|---:|---:|---|
| Daily active users | `DAU` | 10_000 | Unique users who use the service per day. |
| URLs created per user per day | `C` | 10 | Average number of new short URLs per active user. |
| Redirects per created URL per day | `R` | 500 | Average number of redirects generated by one created short URL. Maximum might be 1000. |
| Peak multiplier | `P` | `10x` | Peak requests are assumed to be ten times average requests. |

## Request Volume

```text
URLs created/day = DAU × C
Redirects/day    = URLs created/day × R
```

```text
URLs created/day = 10,000 × 10
                 = 100,000

Redirects/day = 100,000 × 500
              = 50,000,000
```

### Average and Peak QPS

```text
Average creation QPS = 100,000 / 86,400
                     ≈ 1.16

Peak creation QPS = 1.16 × 10
                  ≈ 12
```

```text
Average redirect QPS = 50,000,000 / 86,400
                    ≈ 579

Peak redirect QPS = 579 × 10
                  ≈ 5,790
```

Redirect traffic is much higher than URL creation traffic, so redirect lookups should be fast and scalable.

## Storage Estimation

Assume that one URL record requires approximately 500 bytes, including basic row overhead.

```text
URLs created/day = 100,000
Storage per URL  = 500 bytes
```

```text
Storage/day = 100,000 × 500
            = 50 MB
```

```text
Storage/year = 50 MB × 365
             ≈ 18.2 GB
```

This is raw record storage only. Additional capacity is needed for:

- Indexes
- Database overhead
- Replicas
- Backups

## Design Implications for V1

- Use PostgreSQL as the primary database.
- Add an index on `short_code` for redirect lookups.
- Add an index on `(user_id, created_at)` for listing a user's URLs.
- Use cursor-based pagination.
- Consider caching if redirect traffic increases.
- Use IP-based rate limiting.
