# URL Shortener docs

At this repository, we're going to design a URL shortener system (maybe application). We'll start by gathering the functional and non-functional requirements, and then we'll walk through the design of a reliable and scalable architecture to support it.

## What is the URL Shortener?

A URL shortener is a piece of software that reduces the length of your current URL. As an internet user, you need this tool to share links across the internet :)
